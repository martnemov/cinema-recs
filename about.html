О подборке

Мои оценки

Раздел содержит 1 509 оценок из профиля Марта на Кинопоиске по состоянию на 15 ноября 2026 года. Число на карточке — личная оценка Марта. Порядок по умолчанию следует порядку в профиле.

Обновление через API

При каждом открытии сайта сервер запрашивает все доступные страницы личных оценок профиля martnemov через сторонний сервис Kinopoisk API Unofficial. Ключ хранится только в серверном Secret Vercel. В браузер передаются оценки, а не ключ.

Сервис возвращает около 1500 последних оценок. Они объединяются с полной сохранённой выгрузкой по ID фильма; личная оценка берётся из поля userRating. Отсутствие старой записи в ответе не считается её удалением. Поэтому часть оценок может быть последними известными из архива. Изменения и удаления, не попавшие в доступную часть истории API, автоматически определить нельзя.

Пока идёт загрузка, доступна сохранённая история. Пустые ответы, обрыв страницы и ошибки API не стирают данные. Последняя успешная копия сохраняется в браузере; дополнительный серверный кэш может быть очищен платформой. Уже оценённые произведения скрываются из рекомендаций. Для повторной попытки есть кнопка «Обновить оценки».

Как выбраны рекомендации

Подборка учитывает ваши оценки, общие темы, жанры и стиль. Фильмы доступны за все годы, а при близком соответствии более свежие поднимаются выше. Для сериалов учитываются оценки других сериалов. В анимации есть мультфильмы, мультсериалы и аниме обоих форматов.

Из рекомендаций исключены все записи из выгрузки профиля, включая тайтлы без личной оценки. В подробностях карточки есть причина рекомендации и ссылка на Кинопоиск.

Рейтинги и постеры

В рекомендациях указаны общие рейтинги Кинопоиска на 14–15 ноября 2026 года. Постеры взяты из карточек и профиля Кинопоиска и принадлежат правообладателям.

Сохранённое и просмотренное

Закладки и отметки «Просмотрено» хранятся в текущем браузере. Просмотренные истории скрываются из рекомендаций. Вернуть их можно через «Мои отметки» в каталоге.
