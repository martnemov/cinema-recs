О подборке

Мои оценки

После входа через Яндекс ID подключите открытый профиль Кинопоиска. Импортируются доступные оценки этого профиля.

Как выбраны рекомендации

Сервис ищет похожие фильмы по высоко оценённым произведениям и исключает уже оценённые. Отметки «Просмотрено» хранятся отдельно для каждого аккаунта в браузере.

Данные предоставляются сторонним сервисом Kinopoisk API Unofficial. Полная история просмотров без оценок не гарантируется.
